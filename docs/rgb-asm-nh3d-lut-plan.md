# RGB 실측 실험 계획 — ASM, Neural 3D Holography, 채널별 전역 1D LUT

계획 버전 **v2.1** · 최종 갱신 **2026-11-03 KST** · 상태 **본 실험 착수 전**

카메라로 학습한 전파 모델이 기본 ASM 대비 **실제 컬러 재생 오차를 얼마나 줄이는지**, 그 개선분을 **채널당 전역 1D LUT 하나**로 얼마나 회수하는지 측정한다. R 638 nm, G 520 nm, B 450 nm를 첫 교정부터 함께 진행한다. 원본 장면, 데이터 분할, 스테이지 방문을 공유하고 파장별 위상 패턴, 카메라 관측, 전파 모델, LUT를 구분한다. 최종 평가는 채널별 광학 재생과 실제 RGB 합성 재생을 모두 포함한다.

## 비교군

| 군 | 실제 전송하는 RGB 프레임 |
|---|---|
| A · 기본 ASM | 각 파장의 ASM으로 장면별 최적화한 8-bit 코드를 RGB 프레임에 담는다. |
| B · ASM + LUT | 저장한 A 프레임의 활성 영역에 채널별로 T_R[R], T_G[G], T_B[B]를 한 번 적용한다. |
| C · 학습 모델 | 동결한 R/G/B CNNpropCNN 각각으로 같은 장면의 코드를 재최적화하고 RGB 프레임에 담는다. |

같은 채널의 A와 C는 목표·초기 위상·전파 부호·양자화·목적함수·반복 예산을 맞춘다. 세 군은 같은 출력 면적과 외곽 코드, 레이저 설정, 관측 모드별 노출·좌표·white 기준을 쓴다. 최종 시험을 열기 전에 모델, LUT, 장면, 합성 설정, 평가 규칙을 동결한다.

## 1. 슬롯 분리, 기하 정합, 합성 RGB 기준 확정

- LETO-3의 1920×1080 HDMI 프레임에서 좌상단 (96, 60)의 **1728×960 활성 영역 전체**를 사용한다. 외곽은 세 채널 모두 코드 128로 고정한다. 0 mm에서 영점·정합을 확인하고 기존 스테이지 범위·정지 검사를 적용한다. [출력·촬영 경로](../benchtop/step01_dot_grid.py)
- 설계·관측 깊이는 **1.25, 5.00, 10.00 mm** 세 곳으로 정한다. 가까운 면과 먼 면(1.25, 10.00 mm)의 관측값으로 모델·LUT를 학습하고, 중간 **5.00 mm** 장면 실측값은 최종까지 봉인한다. 보류면의 정합·계측 기준만 미리 얻는다. 세 면 모두에서 설계한 구동 코드를 쓸 수 있으나 보류 관측 영상은 피팅·선택에 쓰지 않는다. 깊이 보간에 대한 결론은 이 한 중간면에 한정한다.
- 각 슬롯에서 관측 대상 채널의 코드를 고정하고 나머지 두 채널을 각각 바꾼다. 슬롯 지연·노출, 목표 채널 신호, 나머지 채널의 영향과 반복 편차를 기록한다. 간섭이 반복 편차를 넘으면 동기·노출을 조정하고 재검사한다. 채널·깊이별 전파 부호, dark/white, 포화, 드리프트, 정합 잔차를 기록한다. 독립 표식 정합 승인 기준은 유효점 ≥20, 네 사분면 포함, 카메라 좌표 RMS ≤3 px, 95백분위 ≤6 px이다.
- **합성 RGB 촬영**은 같은 출력 프레임의 R/G/B 발광 주기를 함께 적분하는 별도 측정이다. 기존 15 ms 노출은 후보로 시험하고 세 슬롯의 포함 비율, 반복성, 포화를 확인해 타이밍을 확정한다. 공통 기하 변환, 카메라 색 변환, 채널 이득과 고정 white를 교정 패턴으로 결정하고 자동 노출·화이트밸런스는 고정한다. 최종 합성 영상에는 공통 정합만 적용해 실제 채널 간 위치 어긋남을 평가에 남긴다.

## 2. 3개 깊이의 RGB 데이터 취득

- 로컬 DIV2K HR은 train 800장, validation 100장이다. 이번 계획은 회전·반전 등 영상 증강 없이, 같은 원본에서도 설계 깊이·합성법·SGD 초기 위상과 반복 수를 달리해 실제로 표시할 위상 패턴을 여럿 만든다. 독립 장면 수는 원본 ID로, 서로 다른 구동 패턴 수는 코드 해시로 센다. [DIV2K 공식 분할](https://data.vision.ee.ethz.ch/cvl/DIV2K/)
- DIV2K 원본을 기준으로 전파 모델 학습·검증, LUT 학습·검증, 최종 시험을 먼저 분리한다. 세 채널은 같은 분할표와 장면 ID를 쓴다. 같은 원본의 crop, 위상 seed, 인접 영상 프레임이 독립 시험 세트로 넘어가는지 검사한다.
- **채널당** 3개 설계 깊이 각각에서 DPAC 100개와 SGD 1,000개를 만든다. SGD 초기 위상·반복 수를 바꾸고 seed를 기록한다. 같은 RGB 장면에서도 목표 성분과 ASM 파장에 맞춰 세 위상 코드를 각각 생성한다. 대응하는 코드 세 개를 하나의 RGB 프레임에 담는다. 설계 깊이와 카메라 관측 깊이는 따로 기록한다. [논문 §3.3](https://www.computationalimaging.org/wp-content/uploads/2021/08/NeuralHolography3D.pdf#page=5)
- **채널당 3,300개 패턴 × 3개 관측면 = 9,900쌍**, 전체 **29,700개 채널–패턴–관측면 쌍**이다. 한 깊이 방문에서 같은 RGB 패턴 목록을 세 슬롯으로 취득한다. 슬롯 타이밍별 블록으로 나눌 때는 대응하는 패턴 ID를 유지한다. 기준 패턴을 주기적으로 재촬영하고 블록 순서를 교차해 드리프트와 채널을 구분한다.
- manifest에는 원본·분할·패턴 ID, 파장, RGB 구동 코드 해시, seed, 두 깊이, 실제 슬롯, 세션, 정합·교정 ID, 장비 readback, 유효·재촬영 판정을 남긴다. 중단 후 누락된 채널–패턴–관측면부터 재개한다. 개발·최종·기준 촬영은 기본 취득량과 별도로 센다.
- 촬영 건당 직접 볼 수 있는 **전체 프레임 8-bit PNG 한 장**을 저장한다. PNG 전달함수를 기록하고 분석 시 선형 강도로 복원해 진폭을 계산한다. 첫 정규 블록에서 채널별 양자화 오차와 실제 파일 크기·처리율·가용 공간을 확인해 전체 소요 시간과 저장 공간을 산정한다.

## 3. 채널별 CNNpropCNN 학습 및 예측 검증

R/G/B마다 **SLM 면 U-Net → 깊이별 ASM → 목표면 공유 U-Net**을 따로 학습한다. 한 파장 안에서 목표면 네트워크를 깊이 간에 공유한다. 픽셀 피치, 유효 거리, 개구, 코드 반전, 정합은 해당 채널의 벤치 설정을 쓴다. 초기 조건은 실측 진폭 L1, Adam, 학습률 0.0005, 배치 1이다. 학습에 사용한 두 깊이의 독립 검증 장면에서 체크포인트를 선택한다. 메모리가 부족하면 채널을 순차 학습하고 깊이별 gradient 누적이나 activation checkpointing을 적용해 전체 화면과 모델 규모를 유지한다. [논문 §3.2–3.4](https://www.computationalimaging.org/wp-content/uploads/2021/08/NeuralHolography3D.pdf#page=5) · [학습 코드](../train.py)

동일한 미학습 구동 코드의 실측 진폭을 ASM과 학습 모델이 각각 얼마나 잘 예측하는지 채널·깊이·화면 위치별로 표를 만든다. **재생 화질**은 다음 단계에서 두 모델이 새로 합성한 홀로그램을 실제 표시해 측정한다.

## 4. A/C 재생 검증과 최종 시험 장면

개발 세트에서 A/C를 실제 표시한다. 주 비교 반복 수 후보는 1,000회이며 개발 수렴 곡선으로 설정을 고정한다. 다중면 위상 정규화를 사용하면 양쪽에 같은 규칙을 적용한다. 최종 시험 장면은 세 채널과 합성 RGB가 공유한다.

| 시험 | 규모 | 관측 방법 |
|---|---:|---|
| 단일면 | 미학습 컬러 자연영상 100장 × 3깊이 | 각 설계 깊이에서 목표 성분별 화질과 실제 컬러 영상 전체를 평가 |
| 다중면 | 미학습 RGBD 30장 × 3관측면 | 장면·방법당 RGB 구동 프레임 하나를 유지하고 3면 스캔. 초점 마스크 안의 재현과 초점 밖 스펙클·깊이 누설을 분리 |
| 진단 | 문자, 가는 선, 저대비 경사, 암부, 고휘도 점, 단색·무채색 경계, 가장자리 구조 | 채널별 세부 대비, 색 번짐, 위치 어긋남, 광량 손실 확인 |

RGBD 출처·장면 ID, 채널 목표 선형화, 깊이 양자화·마스크와 보조 지표 정의를 최종 촬영 전에 고정한다. [논문 그림 5](https://www.computationalimaging.org/wp-content/uploads/2021/08/NeuralHolography3D.pdf#page=8)

## 5. 전역 1D LUT 세 개 학습 및 동결

1. LUT 전용 장면의 단일면·다중면 ASM 코드를 생성한다. 장면 부류별 손실 가중치를 정하고 각 채널의 모델과 입력 코드를 고정한다.
2. 채널별 항등 표에서 시작한다. 그 채널의 보정 코드를 모델로 전파한 진폭이 목표 진폭에 가까워지도록 **표만** 학습한다. 각 표는 동일 채널의 모든 위치·장면·깊이에서 공유한다.
3. 단조 곡선과 256-entry 자유 표 후보를 개발 세트의 채널별 카메라 재생으로 비교한다. 선택한 조합을 실제 컬러로도 확인하고 각 표의 256개 uint8 값, 채널·파장, 해시, 반전 규약, 적용 영역과 광학 조건을 동결한다.
4. 구동 코드 인코딩 후 HDMI 출력 직전에 활성 영역만 치환한다. 세 표가 항등이면 전체 프레임이 A와 바이트 단위로 같아야 한다. 한 표만 바꿨을 때 다른 두 채널과 외곽이 A와 일치하는지도 확인한다. 기존 G 구현은 중앙 512×512용이므로 RGB 전체 활성 영역에 맞춰 확장해야 한다. [기존 추출 코드](../benchtop/fit_green_lut.py) · [기존 적용 코드](../benchtop/green_drive_lut.py)

## 6. 최종 실측, 개선율 및 회수율

- 세 군을 독립적인 **3개 세션**에서 교차 촬영한다. 장면·깊이별 A/B/C 순서를 균형 있게 바꾼다. 한 군의 같은 RGB 구동 프레임을 유지하며 **R, G, B 슬롯 각 1장과 합성 RGB 1장**을 얻는다. 기본 최종 조건 수는 (100 + 30) × 3깊이 × 3군 × 3세션 = **3,510개**다. 슬롯별 **10,530장**과 실제 합성 RGB **3,510장**으로, 총 **14,040장**이다. 기준·진단·재촬영은 별도 집계한다.
- R/G/B 슬롯의 주 지표는 각 채널 고정 white 기준의 실측 진폭 MSE다. 실제 합성 RGB에서는 공통 좌표·색 기준의 선형 RGB 영상을 목표와 비교한다. 주 지표는 픽셀 및 세 성분에 같은 가중치를 준 선형 RGB MSE다. 장면별 이득 재맞춤 없이 SSIM, 세부 대비, 평균 광량, 색 경계 변위와 악화 장면 비율도 보고한다. 합성 결과는 반드시 합성 노출에서 계산한다.
- 각 관측 방식에서 같은 지표로 얻은 평균 오차를 E_A, E_B, E_C라 한다. **모델 개선율 = 1 − E_C/E_A**, **LUT 개선율 = 1 − E_B/E_A**, **개선분 회수율 = (E_A − E_B)/(E_A − E_C)**. R/G/B 슬롯과 합성 RGB에 대해 네 개의 결과를 낸다. 단일면, 다중면 초점부, 보류 깊이를 구분하고 초점 밖 스펙클·누설을 별도 제시한다.
- 반복 촬영을 먼저 평균하고 독립 장면 단위 paired bootstrap으로 95% 신뢰구간을 구한다. 동일 장면의 모든 채널·관측 모드·깊이·군은 함께 재표집한다. A−C 개선이 반복 편차와 구별되지 않는 항목은 절대 차이와 신뢰구간을 보고하고 회수율 판정은 보류한다.
- 속도는 세 LUT 적용 시간, RGB CGH 포함 프레임 생성 시간, 실제 광출력 갱신 시간을 분리해 기록한다.

## 실행 및 갱신 규칙

1. 새 세션을 시작하거나 재개할 때 이 문서의 버전, 현재 상태, 다음 작업과 직전 실행 기록을 읽는다. 실행 설정이 계획과 다르면 차이와 영향을 먼저 기록한다.
2. 촬영·학습 전에 실행 ID, 계획 버전, 코드 버전 또는 스냅샷, 설정·분할표 버전을 결과 위치와 연결한다. 테스트 공개 전에는 모델·LUT·분석 설정의 동결 시점을 남긴다.
3. 각 세션 종료·중단 시 아래 로그에 **실제 수행량, 증거 경로, 결측·실패, 재개 위치**를 추가하고 상단 상태와 다음 작업을 갱신한다. 구현이나 파일 생성만으로 광학 검증을 완료 처리하지 않는다.
4. 깊이, 화면, 표본 수, 분할, 비교군, 지표 등 결론에 영향을 주는 변경은 계획 버전을 올리고 사유·영향·재측정 범위를 기록한다. 이미 수집한 결과의 원래 조건과 이전 결론을 보존한다. 최종 시험을 본 뒤 조정한 모델이나 LUT는 새 버전으로 구분하고 독립 시험 세트를 지정한다.
