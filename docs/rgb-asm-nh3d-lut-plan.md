# RGB DPAC 실시간 LUT 실험 계획

**v3.0 · 2026-11-03 KST · 오늘 실험 종료 · 재개 예정 11월 5일(목)**

**이번 주 산출물**은 실시간 Gaussian Splatting 렌더러가 만든 장면을 DPAC 홀로그램으로 표시할 때 쓸 R/G/B 각 256-entry 8-bit LUT와, 같은 장면에서 LUT 적용 전후를 비교한 카메라 결과다. 11월 5일에 첫 후보를 내보내고 11월 6일(금)에 검증본을 동결한다. [11월 3일 작업 요약](2026-11-03-bench-summary.md)

## 재개 원칙

- 11월 3일 생성한 촬영·패턴·데이터 분할·교정 파일 전량 폐기. 당시 수치는 작업 기록으로만 보관. 새 실측과 새 분할표로 시작.
- 모든 최상위 결과 폴더 이름은 한국 시각 기준 `results/YYYYMMDD-hhmmss_사람이-읽을-수-있는-설명/`. 예시 `20261105-093000_rgb-dpac-lut-fit/`. 기존 폴더 덮어쓰기 금지. 한 실행의 패턴·촬영·표는 그 폴더 안의 하위 폴더로 관리.
- 생성 경로는 렌더 RGB → 선형 강도 → 진폭 → 파장별 단일 패스 DPAC → 기존 반전 8-bit 인코딩 → 채널별 LUT 조회 → HDMI. 데이터셋의 모든 패턴을 DPAC으로 생성. 디스플레이 시점에는 카메라 또는 반복 최적화 없이 표만 조회.
- 전체 1728×960 활성 영역, ND 0.4, R/G/B 638/520/450 nm, 설계·관측면 3/5/7/9 mm. 3/7/9 mm로 학습·선택하고 5 mm 장면은 마지막 보간 확인에 사용. 0 mm는 광학 영점. 기존 영점 100.780 mm와 이전 노출은 시작 후보값이며 재개 시 readback·정합·포화·dark/white 재확인.

## 11월 5일 목요일 · 당일 후보 LUT 추출

1. **벤치 복구 및 기준 측정.** 정지·호밍·이동 한계·HDMI 출력 확인 후 새 실행 폴더에 깊이별 정합, 암·백색, 슬롯 분리 및 합성 노출 확인 결과 기록. 장면 촬영 1건당 직접 보는 전체 프레임 8-bit PNG 1장. 유효 영역을 정합한 뒤 지표 계산.
2. **DPAC 전용 데이터 생성.** 실제 Gaussian Splatting RGB 렌더 프레임 우선. 동일 장면의 인접 시점은 한 분할에만 배정. 렌더 자료 준비 전에는 DIV2K로 후보를 먼저 생성하고, 렌더러 장면 전이 검증 여부를 별도 표기. 기본 상한은 적합 24장·선택 8장·최종 8장. 앞 두 집합은 3/7/9 mm, 최종 집합은 3/5/7/9 mm로 합성하여 최대 128개 RGB 구동 프레임. 촬영은 해당 패턴의 설계면에서 수행. 입력 원본·깊이·구동 코드 해시 기록.
3. **실측으로 LUT 직접 선택.** 기준 A는 항등 LUT, 후보 B는 A와 완전히 같은 DPAC 프레임에 표 한 번 적용. 채널당 입력 코드 0/64/128/192/255에 제어점을 두고 양 끝을 고정. 내부점 하나씩 출력을 ±12코드 움직여 단조 선형 보간 후 256개 uint8 값으로 양자화. 먼저 적합 집합에서 깊이당 2장으로 후보와 기준을 교차 촬영하고, 각 채널의 고정 백색 진폭 MSE로 선택. 항등 표도 후보에 포함. 각 채널의 선택 결과를 합친 뒤 독립 선택 장면에서 컬러 재생을 확인. 1회 탐색으로 첫 후보를 즉시 저장하고 남는 시간에만 작은 폭으로 2차 탐색.
4. **목요일 종료 시 인계.** RGB 표를 포함한 NPZ, 표 방향·적용 순서·파장·활성 영역·광학 조건·체크섬·항등 우회 방법을 담은 메타데이터, 설계면별 실측 A/B 표 저장. 논문 규모의 전파 모델 학습, SGD 위상 생성, 전 장면의 모든 깊이 스캔은 이번 주 일정에서 제외.

재개 시 데이터 생성 명령 예시(PowerShell, 저장소 루트 기준):

```powershell
.\.venv\Scripts\python.exe -m benchtop.dpac_lut_dataset (Join-Path $env:USERPROFILE 'Documents/DIV2K dataset')
```

렌더 프레임을 사용할 때는 데이터셋 인수에 `fit/<scene>/*.png`, `selection/<scene>/*.png`, `test/<scene>/*.png` 구조의 루트를 전달한다. 이 명령은 시각 접두사 생성, 분할, DPAC 구동 PNG 저장까지 담당한다. 새 폴더에 대한 촬영·LUT 탐색 실행은 목요일 첫 작업으로 연결한다. 이전 실행 경로가 고정된 v2.x 스크립트의 기본 명령은 폐기 데이터에 의존한다.

## 11월 6일 금요일 · 검증본 동결 및 다음 주 인계

- 오전 중 후보를 동결한 뒤 미사용 장면으로 A/B 순서를 바꾸어 2회 이상 반복. RGB 합성 영상과 슬롯별 고정 백색 MSE, PSNR·SSIM, 평균 밝기를 같은 조건에서 비교. 깊이별 개선 장면 수·악화 장면 수와 반복 편차 기록.
- 가능하면 실제 Gaussian Splatting 장면 2개 이상의 서로 다른 시점 또는 짧은 시퀀스에서 출력·색 변화 확인. LUT 조회 시간과 전체 DPAC→표시 프레임 시간 분리 기록. DIV2K만 확인한 경우에는 실제 렌더 장면 전이 검증을 다음 주 첫 항목으로 명시.
- 금요일 오후에 검증한 표, 적용 예제 `out[..., c] = table[c][in_codes[..., c]]`, 항등 표와 대표 비교 결과 인계. 개선이 반복 편차보다 작은 채널은 항등을 기본값으로 두고 측정한 후보와 결과를 함께 제공. 광학적 개선을 확인한 범위만 기록.
- 실행 종료·중단 시 이 문서에 실행 폴더, 실제 수행량, 판정, 다음 작업 추가. 이번 주 마감의 우선순위는 검증 가능한 LUT 인계와 DPAC 재생 경로 확보.
