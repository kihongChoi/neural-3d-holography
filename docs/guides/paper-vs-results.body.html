01 / 결론부터 읽기

실측 프레임워크는 구축됐다.
논문의 핵심 성능 재현은 아직 남아 있다.

현재 성과는 15 mm 단일 평면에서 RGB 촬영·학습·위상 생성·CITL·검증을 연결한 것이다. CNN은 저장된 카메라 진폭을 더 잘 예측하지만, CNN 단독으로 최적화한 홀로그램의 최종 실측 품질은 ASM보다 평균적으로 좋아지지 않았다.

세 수치는 모두 진폭 MSE 기준이며 서로 다른 평가 문제를 포함한다. 첫 수치를 곧바로 “홀로그램 품질 60% 향상”으로 읽으면 안 된다. 현재 가장 분명한 개선은 카메라가 실제 오차를 알려주는 CITL을 추가했을 때 나타났다.

비유 · 지도와 길찾기
지도의 현재 위치를 정확히 표시하는 능력과, 어느 방향으로 걸으면 목적지에 가까워지는지 알려주는 능력은 다르다. 여기서 전자는 forward 예측, 후자는 모델의 기울기와 위상 최적화다.
현재 보고에 사용할 문장: “단일 평면 RGB 실측 파이프라인과 소형 전파 보정 모델을 구축했다. 보관 test의 진폭 예측 MSE는 감소했으나, 최종 8개 타깃에서 CNN 단독 생성의 평균 실측 개선은 확인되지 않았다. CNN+CITL은 ASM 대비 평균 MSE를 약 49.6% 줄였다.”

04 / 지표 해석

무엇과 무엇의 차이를 재는가

A. Forward prediction

입력 위상은 고정한다. 모델이 예측한 진폭과 그 위상으로 과거 촬영한 카메라 진폭을 비교한다.

MSEpred = mean[(Â(φ) − Acamera(φ))²]

sealed test 8개 ID × RGB 3채널. ASM 0.062147 → CNN 0.024941. 약 59.9% 감소.

B. Target reconstruction

목표 이미지에 맞춰 위상을 새로 최적화한다. 실제 카메라 진폭을 원하는 타깃 진폭과 비교한다.

MSEtarget = mean[(Acamera(φ*) − Atarget)²]

최종 8개 ID × 방식별 3회. ASM 0.110675, CNN 0.115093, CNN+CITL 0.055739.

논문 Table 1의 forward 예측 PSNR과 Fig. 4/5의 생성 영상 PSNR은 다른 평가다. 현재 진폭 MSE를 −10 log₁₀(MSE)로 바꿔도 논문의 PSNR과 바로 비교할 수 없다. 픽셀 영역, amplitude/intensity, 스케일, 색 결합, 정렬, 이미지 집합과 집계 순서를 먼저 일치시켜야 한다.
정규화와 평균의 정확한 정의

타깃은 sRGB → 선형 강도 → resize/crop → 제곱근 진폭 순서로 만든다. 카메라는 채널별 고정 calibration white로 정규화한다. 최종 실측은 한 실행의 ROI 1680×960과 scale=1을 사용한다. 이 문서의 MSE는 각 촬영의 RGB·픽셀 평균 MSE를 먼저 계산하고, 3회 촬영과 8개 ID를 평균한 값이다. 평균 영상을 만든 뒤 그 영상에서 계산한 MSE와는 노이즈 항 때문에 조금 다르다. 미리보기는 평균 진폭을 제곱하고 sRGB로 표시하므로 눈으로 보는 밝기는 진폭 값 그 자체가 아니다.

실험 예산도 동등한가?

최종 ASM과 CNN 위상은 같은 난수 초기 위상에서 각 80 step으로 생성했다. CNN+CITL은 CNN 결과에서 시작해 실제 카메라 피드백으로 최대 1,000 step을 추가했다. 따라서 약 49.6% 개선은 카메라 피드백과 추가 계산을 포함한 전체 절차의 이득이다. 동일 시간 예산에서 CNN이 우수하다는 증거로 사용하면 안 된다.

05 / 원본 최종 실측

8개 타깃을 같은 기준으로 비교하기

CNN 단독은 8장 중 2장에서만 ASM보다 낮은 평균 MSE였다. CNN+CITL은 8장 모두 개선됐다. 아래 그래프와 표는 동일한 저장 측정값을 사용한다.

IDASMCNNCNN+CITLCITL best step종료

실제 저장된 카메라 평균 영상의 축소 미리보기. 각 방식의 수치는 평균 영상의 MSE가 아니라 개별 재촬영 MSE의 평균이다.

최고 성능을 얻은 순간과 종료 순간은 다르다

최종 8장 중 7장은 1,000회 상한에 도달했다. 0808만 960회에 프로그램의 plateau 기준을 충족했다. 이 한 건의 converged도 수학적 수렴이나 최적점 도달의 증명이 아니다. 최종 비교에는 종료 위상이 아니라 실제 측정 loss가 가장 낮았던 위상을 보관해 다시 촬영했다.

종료 조건 읽기

최소 200회 이후, 매 20회마다 인접한 두 20개 loss 창의 중앙값을 비교한다. 변화의 절댓값이 max(10⁻⁵, 이전 중앙값×0.002) 이하인 판정이 세 번 연속이면 종료한다. 그렇지 않으면 최대 1,000회다. 최적 loss가 초반에 나온 뒤 악화되어도, “악화했음” 자체로는 이 조건이 종료되지 않는다. 그래프는 10 step 간격과 best/end 지점을 보여준다.

관측과 가설을 구분하기

관측: 고정 위상 drift, 낮은 국소 응답 cosine, 일부 방향 미분 부호 불일치, 학습률에 따른 후기 loss 차이. 응답 영상에 σ=2 pixel 평활화를 적용하면 cosine이 올라가는 사례도 있다.

가설: 공간 등록·고주파 응답·유효 개구·SLM 위상 응답·편광/시간 변동·학습 분포 및 모델 표현력이 영향을 줄 수 있다. 평활화 개선만으로 등록 오차를 원인으로 확정할 수 없고, 측정값의 drift만으로 CITL 악화를 전부 설명할 수도 없다.

제한: 두 타깃, 동일 예산 200 step, 조건별 optimizer 재실행 반복 없음. 2쌍 측정의 SE는 신뢰구간이 아니다. 원본 최종 평가와 후속 진단은 시점이 다르므로 절대 MSE를 단순 합산하지 않는다.

근거: 진단 요약, 해석 범위, 섭동 측정.

07 / 다음 실험 가이드

학습 시간 확대 전에 검증할 순서

아래는 실행된 실험이 아니라, 현재 근거에서 도출한 후속 제안이다. 수치 합격선을 임의로 정하지 말고 반복 노이즈와 실험 목적을 기준으로 사전 등록한다.

우선순위실험통제할 조건다음 단계로 넘어갈 근거
1 · 측정 신뢰도고정 위상 기준을 전후·중간에 반복. 채널별 registration 잔차, 포화·dark·white, trigger와 실제 SLM 출력 확인노출·레이저·LUT·정규화·ROI·표시 순서 기록방법 간 차이가 세션 내 반복 변동으로 설명되는지 판단 가능
2 · 최적화 정책lr·best 선택·후기 악화 종료를 별도 개발 타깃에서 비교. ASM+CITL도 같은 초기값·예산으로 비교여러 초기화, 시간 블록, 카메라 횟수·총 시간 맞춤현재 CNN+CITL 개선 중 모델과 카메라 피드백의 기여 분리
3 · 모델 ablationASM → gain-only → 현재 amplitude CNN → 복소장 타깃 CNN → SLM CNN → CNNpropCNN동일 split·측정쌍·최적화 예산. 모델 용량 변화 기록예측 MSE·국소 응답·최종 타깃 실측이 함께 개선
4 · 데이터 분포생성 알고리즘·초기 위상·반복 수를 다양화. 최적화 경로에서의 phase/camera 쌍 포함 여부 비교학습 데이터 선택에 최종 평가 ID 사용 금지학습 분포 밖의 새 위상·새 이미지에서도 이득 유지
5 · 3D 확장장비상 가능한 여러 깊이 촬영·보정 → 학습에서 제외한 깊이 → RGBD 마스크 → 위상 정규화깊이별 좌표·노출·전파 거리·타깃 CNN 공유in-focus와 out-of-focus를 따로 평가하고 held-out depth 입증

이미 살펴본 최종 8장, 특히 후속 진단에 사용한 0846·0898은 이제 개발 참고 자료다. 새 모델이나 하이퍼파라미터를 이 자료로 선택했다면 다음 일반화 주장은 새로 봉인한 이미지와 촬영 세션에서 평가해야 한다.

08 / 보고 전 점검

확인한 사실만 한 문장씩 적기

원본·계산 경로와 검증 범위

evidence-snapshot.json에는 타깃별 반복 측정, 집계값, split 교집합(모두 0), 종료 기록, 파일 SHA-256을 넣었다. build_guides.py는 원본 JSON에서 이를 다시 만든다. 이 문서는 저장된 측정과 코드를 확인한 결과이며, 장비 재가동이나 새 촬영은 하지 않았다. 기존 42개 테스트 통과는 후속 진단 당시 기록으로, 이번 문서 작성에서 새로 전체 실험 테스트를 실행했다는 뜻은 아니다.
